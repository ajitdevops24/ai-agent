1. PROJECT SUMMARY
--------------------------------------------------------------------------------
Project KubeCore aims to containerize and migrate the company's legacy monolithic 
customer portal into a highly available, auto-scaling Kubernetes cluster hosted 
on AWS (EKS). 

The primary business drivers are reducing cloud infrastructure spend, improving 
application deployment frequencies from bi-weekly to multiple times per day, 
and ensuring zero-downtime upgrades via rolling deployment strategies.

Key Deliverables:
* Production-ready AWS EKS Cluster infrastructure built via Terraform.
* Automated CI/CD deployment pipelines using GitHub Actions and ArgoCD.
* Migrated Customer Portal microservices with centralized logging (Grafana Loki) 
  and monitoring (Prometheus/Grafana).
